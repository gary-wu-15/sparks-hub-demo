# Sparks hub demo

Unofficial interactive prototype, not a live M&S service. Account details are fictional. No authentication, transactions or real reward activations. Changes are browser-local. The source screenshot, original customer IDs, scores, source metadata and private project history are excluded.

The landing page is the persona gallery: 50 latest examples across 10 segments, plus archived datasets. `prototype.html` opens the current studio. `v1-page/` preserves the previously published prototype (26f0a33), independently of the latest designs. Public CSVs contain generated DEMO IDs, illustrative scores and component order only.

Serve this directory using any static HTTPS host. The default fixture is `hub.json`. Remote data sources must support CORS and must not expose personal information. Photography and branding belong to their respective owners; no licence for reuse is granted by this demo.
